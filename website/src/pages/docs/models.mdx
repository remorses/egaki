# Models

egaki supports models from **Google**, **OpenAI**, **xAI**, **Fal.ai**, **Replicate**,
**ElevenLabs**, **Cartesia**, **Deepgram**, and **Groq**.

## Discover models

```bash
# All models
egaki models

# Filter by type
egaki models --type image
egaki models --type video
egaki models --type speech
egaki models --type transcription

# Filter by provider
egaki models --provider google
egaki models --provider openai

# JSON output for scripting
egaki models --json
```

## Vertex AI routing

Prefix any Google model with `vertex/` to route through Vertex AI
(Google Cloud billing) instead of Google AI Studio:

```bash
egaki image "photo" -m vertex/imagen-4.0-generate-001 -o photo.png
egaki video "clip" -m vertex/veo-3.1-generate-001 -o clip.mp4
```
