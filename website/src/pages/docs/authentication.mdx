# Authentication

egaki supports multiple authentication modes. You can mix and match: use ChatGPT auth
for OpenAI models, a Google key for Imagen, and an egaki subscription for everything else.

## Provider keys (BYOK)

Add API keys for individual providers with `egaki login`:

```bash
# Google AI Studio (Imagen, Gemini, Veo)
egaki login --provider google --key AIza...

# OpenAI (GPT Image, DALL-E)
egaki login --provider openai --key sk-...

# xAI (Grok Imagine)
egaki login --provider xai --key xai-...

# Fal.ai (Flux, Recraft)
egaki login --provider fal --key ...

# Replicate
egaki login --provider replicate --key r8_...
```

Keys are stored in `~/.config/egaki/credentials.json` with file mode `0600`.

## ChatGPT OAuth

Log in with your existing ChatGPT account. This routes image requests through the
ChatGPT/Codex backend, using your ChatGPT Plus/Pro subscription credits.

```bash
egaki login --provider chatgpt
```

Opens a browser for OAuth. After approval, use OpenAI image models:

```bash
egaki image "dreamy bakery at sunrise" -m gpt-image-1.5 -o bakery.png
```

## xAI Grok Build OAuth

Log in with your Grok Build subscription via browser OAuth:

```bash
egaki login --provider xai-oauth
```

This gives you access to `grok-imagine-image` and `grok-imagine-video` models
using your Grok Build subscription credits.

## Vertex AI (Google Cloud billing)

Prefix model IDs with `vertex/` to route through Vertex AI instead of Google AI Studio.
This uses Google Cloud billing instead of AI Studio quotas.

```bash
egaki login --provider vertex --key AIza...
egaki image "editorial sneaker photo" -m vertex/imagen-4.0-generate-001 -o sneaker.png
egaki video "storm over mountains" -m vertex/veo-3.1-fast-generate-001 -o storm.mp4
```

<Aside>
<Tip>
Vertex AI and Google AI Studio use different billing. Vertex charges through
your Google Cloud project. AI Studio has free tier quotas for many models.
</Tip>
</Aside>

## Egaki subscription

One API key for all supported models. Two plans:

| Plan | Price | Monthly usage budget |
|------|-------|----------------------|
| Plus | $29/mo | $29 of generation usage |
| Pro | $99/mo | $99 of generation usage |

Usage is tracked in dollars, not credits: each generation counts its
provider cost (with a markup) against your monthly budget. The budget
resets every 30 days. As a reference, $29 covers roughly 500 standard
Imagen images.

Buy directly with these links (opening `/buy` without a plan defaults
to Plus):

- Plus: [egaki.org/buy?plan=plus](https://egaki.org/buy?plan=plus)
- Pro: [egaki.org/buy?plan=pro](https://egaki.org/buy?plan=pro)

```bash
# Subscribe (opens checkout URL); plan is plus or pro
egaki subscribe --plan plus --email user@example.com

# Save the key after checkout
egaki login --provider egaki --key egaki_...

# Check usage
egaki usage

# Cancel
egaki unsubscribe
```

## Check configured providers

```bash
egaki login --show
```

Shows which providers are configured and their status (valid key, expired, etc.).

## Remove a provider key

```bash
egaki login --remove google
```
