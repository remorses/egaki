New package with the `AngledScreen` shader, usable without egaki. Run `npx @egaki/angled-screen screenshot.png -o hero.png` to turn any image into a tilted 3D screen with depth of field, fog, chromatic aberration and grain. It renders in your Chrome through the Playwriter extension and writes PNG, JPG or WebP. Web apps can import `renderImage` or `createAngledScreenRenderer` directly.
