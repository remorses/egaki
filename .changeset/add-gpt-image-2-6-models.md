Add `gpt-image-2.6-sunburst` and `gpt-image-2.6-flare` to the model catalog. OpenAI released both on 2026-11-04. They work with API keys and with ChatGPT login (`egaki login --provider chatgpt`), for example `egaki image "a fox reading a map" -m gpt-image-2.6-sunburst`. Quality levels and pricing are set equal to GPT Image 2.5 until OpenAI publishes the 2.6 values.
